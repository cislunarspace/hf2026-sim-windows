## 一句话概括

提出ELPIO（精英学习-局部搜索鸽群优化）算法，通过在传统鸽群优化的两个导航阶段分别引入精英学习因子和局部搜索策略，解决超低空电磁威胁域中无人机群协同路径规划收敛慢、易陷入局部最优的问题。

## 核心方法/模型

### 环境建模

对超低空电磁威胁域中三类障碍物分别建模：

1. **建筑物**：立方体模型，威胁区域由安全距离 $d_\text{safe}^b$ 和危险距离 $d_\text{danger}^b$ 界定
2. **民用公共设施**（信号塔、电线杆等）：圆柱体模型，威胁区域由半径 $r_j$、高度 $H_j$ 及导航定位误差 $d_s^p$ 和无人机直径 $d_\text{UAV}$ 共同决定
3. **电磁威胁域**：半球形模型，威胁区域由电磁波威胁域半径 $R_j$ 和有效探测距离 $R_j'$ 界定

### 代价函数

总代价函数为六项加权和：

$$J = \alpha_b J_b + \alpha_p J_p + \alpha_e J_e + \alpha_r J_r + \alpha_\psi J_\psi + \alpha_h J_h$$

- $J_b$：建筑物威胁代价（碰撞区=1，威胁区按距离衰减，安全区=0）
- $J_p$：民用公共设施威胁代价（类似分段结构）
- $J_e$：电磁威胁代价（有效探测距离内=1，外部按距离四次方衰减）
- $J_r$：路径代价（航路点间欧氏距离之和）
- $J_\psi$：航向代价（偏航角之和，$\psi_\text{max}$ 为最大偏航角）
- $J_h$：飞行高度代价（$m_i g \Delta h$，相邻航路点势能差）

权重满足 $\alpha_b + \alpha_p + \alpha_e + \alpha_r + \alpha_\psi + \alpha_h = 1$。

### ELPIO算法（核心改进）

在经典鸽群优化（PIO）的两个阶段分别改进：

**第一阶段（地图和指南针算子）—— 引入精英学习因子：**
- 速度更新公式增加精英学习项 $c_1 \cdot (X_p^{k-1} - X_i^{k-1})$，其中 $X_p^{k-1}$ 为历史精英鸽（上一代最优鸽）
- 采用竞争机制：若精英学习后代价值更差，则退化为原始更新（$c_1 = 0$）

**第二阶段（地标算子）—— 引入局部搜索策略：**
- 从剩余鸽群中用轮盘赌策略选取部分个体进行精细局部搜索
- 使用模式矩阵 $P_k = BC$ 确定搜索方向和步长
- 简化设定：$B = I$（单位矩阵），$\Gamma_k = (I, -I)$，$L_k = 0$
- 设置步长阈值 $\hat{\Delta}$ 避免持续陷入局部最优

**算法复杂度**：$O(N^m (N^k \log N^k + D \log N^k + F \log N^k))$

## 关键参数/实验数据

### 实验设置
- 仿真场景：500m x 500m x 100m 超低空电磁威胁域
- 5架无人机，起点分布在x=10m一侧，目标点位于(470, 420, 90)附近
- 各算法种群数量 K/N = 30
- 各算法最大迭代次数相同，执行25次取平均

### ELPIO参数
- 鸽子数量 N = 30
- 地图和指南针算子因数 R = 0.3
- 局部搜索步长阈值：$\Delta = \Delta_0 / 2^7$

### 对比算法参数
- PSO/CPSO：惯性权值 w = 0.2，认知学习因子 $c_1$ = 1.5，社会学习因子 $c_2$ = 1.5
- CPSO额外参数：柯西分布概率密度参数 a = 1

### 性能结果
- ELPIO在第11次迭代时收敛速度已超过PIO、PSO、CPSO
- 在第28代收敛到总航路代价最低值
- 经过25次独立运行，ELPIO航路代价值最低，全局搜索能力最强
- Gazebo虚拟场景验证中5架无人机均安全避障到达目标

## 结论

1. ELPIO算法收敛速度显著快于传统PIO、PSO和CPSO，且不易陷入局部最优
2. 在超低空电磁威胁域内航路代价值最低
3. 通过Gazebo虚拟场景验证了工程实用性
4. 局限性：尚未在真实超低空环境中进行实飞验证；代价函数权重为手动设定，缺乏自适应机制

## 对本项目的可用点

### 直接可用
1. **障碍物建模体系**：三类障碍物（建筑物-立方体、公共设施-圆柱体、电磁威胁-半球形）的建模方式可直接用于竞赛中城市超低空场景的威胁域构建
2. **代价函数框架**：六项加权代价函数（威胁+路径+航向+高度）的结构可作为竞赛路径规划模块的目标函数模板
3. **威胁代价的分段设计**：碰撞区/威胁区/安全区三段式威胁评估，以及电磁威胁按距离四次方衰减的模型，可用于电磁威胁仿真模块

### 参数参考
- 种群规模30、最大迭代次数28代左右即可收敛，适合实时性要求较高的场景
- 权重和为1的约束条件下的各权重分配思路可参考
- 航路点间距离、偏航角、高度差等代价项的计算公式可直接复用

### 限制条件
- 论文为离线全局规划，未涉及动态避障和在线重规划
- 电磁威胁模型较为简化（半球形固定区域），未考虑电磁传播的频率依赖性和衰减特性
- 代价函数权重手动设定，竞赛中可能需要自适应调参
- 论文仅考虑5架无人机的小规模集群，大规模集群的可扩展性需进一步验证
