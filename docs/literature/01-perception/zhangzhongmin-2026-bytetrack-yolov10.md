## 一句话概括

针对无人机场景下多目标跟踪精度与实时性难平衡的问题，用小目标检测器 MT-YOLOv10 替换 YOLOv10、以功率自适应卡尔曼滤波（PAKF）加轨迹置信度改进 ByteTrack（PAC-ByteTrack），在 VisDrone2019-MOT 上 HOTA 提升 4.467% 且保持 38 FPS 实时性。

## 核心方法/模型

整体是 TBD（Tracking-By-Detection）级联架构：MT-YOLOv10 检测器输出检测框与置信度，送入 PAC-ByteTrack 完成数据关联与轨迹管理。

**检测器 MT-YOLOv10**（基于 YOLOv10 的两处改动）：

1. **MSKFF 特征融合模块**：改进自 MIRNet 的 SKFF。先用 1×1 卷积把浅层特征图的通道数对齐到另一输入，再对两路特征图做通道级注意力加权融合（GAP → 1×1 卷积+激活 → 生成权重），替代 Neck 中的 Concat 拼接。加权融合自适应抑制冗余特征，比拼接省计算。
2. **检测头调整**：增加 Tiny 小目标检测层（输入特征图尺寸更大、感受野更小），同时删掉对大目标有效的 Large 层。Tiny 层使 P/mAP50 提升 4.1%/6%，删 Large 层后精度几乎不降、参数量从 9.44M 降到 7.43M。

**跟踪器 PAC-ByteTrack**（基于 ByteTrack 的三处改动）：

1. **PAKF 功率自适应卡尔曼滤波**：在预测环节用自适应系数 λ_t = 1 − IOU(a_j^{t−1})^α 调整过程噪声 Q_t（关联代价越大，下一轮过程噪声越大）；在更新环节用自适应因子 ξ_t = 1 − (c_t)^β 按检测置信度 c_t 调整测量噪声 R_t（置信度越低，测量噪声越大、KF 越不信任观测）。超参数取文献[16]的实验最优值 α = 2.5，β = 0.1。
2. **轨迹置信度弱特征关联**：借鉴 HybridSort，对第二次关联中的低置信度轨迹，用线性预测代替 KF 预测轨迹置信度（式 8：ĉ_trk = c^{t−1} − (c^{t−2} − c^{t−1})），以轨迹置信度估计值与检测置信度的绝对差 C_conf = |ĉ_trk − c_det| 作为关联代价的一部分。因为 KF 有滞后性，在遮挡开始/结束、目标快速变化时线性预测更可靠。
3. **KF 状态向量调整**：从 ByteTrack 的 8 元组 [x_c, y_c, a, h, ẋ_c, ẏ_c, ȧ, ḣ]（宽高比+高度）改为直接预测宽高的 9 元组（含置信度）x = [x_c, y_c, w, c, h, ẋ_c, ẏ_c, ẇ, ḣ, ċ]，与检测框的 IOU 匹配更好。

## 关键参数/实验数据

**PAKF 超参数**：α = 2.5（IOU 代价惩罚系数），β = 0.1（置信度衰减系数），照搬 Liu et al. 2023（Multimedia Systems）的实验最优值。

**检测训练配置**：VisDrone2019-DET（训练集 6471 张、验证集 548 张）；RTX 4090；Python 3.9 + Torch 2.5.1 + CUDA 12.4；Epoch 200、Batch Size 8、学习率 0.01、SGD、早停 50。

**检测消融（VisDrone2019-DET）**：

| 配置 | P/% | R/% | mAP50/% | 参数量/M |
|---|---|---|---|---|
| YOLOv10s baseline | 49.5 | 37.8 | 38.5 | 8.07 |
| +Tiny 检测头 | 53.6 | 43.1 | 44.5 | 9.44 |
| +Tiny −Large | 53.6 | 42.7 | 44.5 | 7.43 |
| +MSKFF（MT-YOLOv10） | 53.8 | 44.0 | 45.0 | 7.56 |

横向对比（mAP50 / mAP50:95 / 参数量 M）：MT-YOLOv10 45.0 / 27.6 / 7.56，优于 YOLOv11s（39.5/23.7/9.42）、YOLOv9s（34.6/20.1/7.17）、YOLOv5s（34.4/19.0/7.04）、RetinaNet（44.3/22.7/36.4）。类别上 pedestrian、people 提升最大（各 +12%），car +7%。

**跟踪消融（VisDrone2019-MOT-test，ByteTrack 基线 HOTA 39.809 / MOTA 38.051 / IDF1 49.416 / FPS 53.2）**：

- 仅改状态向量（Xywh）：HOTA +0.817，MOTA +0.551，IDF1 +0.425
- 仅加轨迹置信度（score）：HOTA +0.252，MOTA +0.787，IDF1 +0.274
- 仅 PAKF：HOTA +1.747（41.556），单组件中提升最大
- 三者全开（PAC-ByteTrack）：HOTA 41.64（+1.831），MOTA 39.222，IDF1 51.248，FPS 52.5
- UAVDT-test 上同样有效：HOTA +0.448，IDF1 +0.57

**检测器×跟踪器组合（VisDrone2019-MOT-test）**：MT-YOLOv10 + PAC-ByteTrack 达到 HOTA 44.483 / MOTA 41.746 / IDF1 56.492 / IDSW 924 / FPS 38.387，较 YOLOv10 + ByteTrack 基线 HOTA +4.467、MOTA +3.695、IDF1 +6.976，FPS 降约 4.3。检测器升级（+2.727 HOTA）贡献大于跟踪器升级（+1.831 HOTA），印证 TBD 范式对检测器依赖强。

**与主流跟踪算法对比（VisDrone2019-MOT-test，FPS）**：本文 38.4，介于 ByteTrack（53.2）与 StrongSort（13.8）之间；HOTA 44.483 低于 StrongSort 的 45.337 但 FPS 是其 2.8 倍，优于 OCSort（40.9）、HybridSort（41.5）、NanoTrack（40.3）、ByteTrack（39.8）。实时性实验平台为 RTX 2070 SUPER + Windows + Torch 1.12.1。

## 结论

MT-YOLOv10 与 PAC-ByteTrack 组合在无人机 MOT 任务上兼顾精度与实时性，HOTA 指标优于大多数主流 TBD 算法，遮挡和俯视小目标场景下轨迹连续稳定。局限性：只用了运动信息，未融合外观特征（ReID）等多模态信息；复杂环境变化和长时间遮挡下跟踪仍不稳定；TBD 范式性能上限受检测器制约，小目标检测与轻量化检测是后续方向。

## 对本项目的可用点

红枫 2026 赛题三涉及无人机对地面/空中目标的搜索、跟踪与鉴别，本文几乎是一份可直接落地的跟踪模块参考实现：

1. **跟踪模块（07-tracking）首选基线**：ByteTrack + PAKF + 轨迹置信度 + xywh 状态向量，改动小、不依赖 ReID 模型、纯运动信息即可跑，适合竞赛中先搭起可用的跟踪器。三个组件各自独立、可逐个消融验证，工程风险低。
2. **可直接抄的参数**：PAKF 的 α = 2.5、β = 0.1 是文献验证过的最优点，不必自己调；状态向量用 [x_c, y_c, w, h, ẋ_c, ẏ_c, ẇ, ḣ]（置信度维度可选）；检测置信度低阈值沿用 ByteTrack 二次关联策略。
3. **检测器侧的设计启示**：若仿真平台给出的机载相机图像目标偏小（俯视、远距离），"加 Tiny 层、删 Large 层"是性价比最高的 YOLO 改造——精度涨、参数量反降。MSKFF 收益相对小（mAP50 +0.5%），优先级低。
4. **性能基准参考**：论文在 RTX 2070 SUPER 上做到 38 FPS，说明该方案在普通 GPU 上满足 30 FPS 实时线；若我们的推理环境更弱（如纯 CPU 或平台 API 限制帧率），需进一步轻量化检测器。
5. **限制条件**：方案不含 ReID，长时遮挡后身份恢复能力弱——若赛题评分看重 ID 一致性（IDF1/IDSW），需在 PAC-ByteTrack 基础上再补外观特征或重识别机制；本文 IDSW（924）其实高于 ByteTrack 基线（901），身份切换问题并未因精度提升而改善，这一点要警惕。
