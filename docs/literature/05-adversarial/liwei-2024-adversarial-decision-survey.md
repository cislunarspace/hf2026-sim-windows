## 一句话概括

系统梳理了无人机集群对抗决策的三大类算法（基于规则、基于博弈论、基于神经网络），并提出信用分配模型和角色化多智能体强化学习两种改进思路来解决现有MARL方法的不足。

## 核心方法/模型

本文是综述性质，本身不提出单一新模型，但对三类决策算法做了体系化归纳，并在第3节介绍了作者团队的两个自研模型：

### 1. 基于规则的方法

- **专家系统**：将专家知识构建为规则库，将战场态势与规则匹配进行决策。优势是决策速度快、可解释性好；劣势是对未知情况适应性差。
- **贝叶斯网络**：用有向无环图表示变量间的依赖关系，联合概率分布为各节点条件概率的乘积（公式1）。动态贝叶斯网络在时间维度上扩展，可用于推理敌方意图和轨迹预测。

### 2. 基于博弈论的方法

- **博弈对抗决策模型**：确定策略集合 → 构建态势优势函数（综合角度、速度、距离等因素，加权求和） → 构建收益矩阵 → 求解纳什均衡。变体包括：非完全信息动态博弈（贝叶斯纳什均衡）、多稳定性分析（纳什稳定性+元理性+序贯稳定性）、模糊信息博弈。
- **群体智能算法求解纳什均衡**：
  - **粒子群算法（PSO）**：粒子跟踪个体极值和全局最优位置更新速度和位置（公式2）。变体有混合捕食者-猎物粒子群算法。
  - **蚁群算法（ACO）**：通过信息素机制搜索优化路径（公式3），用于协同搜索和攻击任务规划。
  - **人工鱼群算法**：利用觅食、聚群、追尾、随机游动行为解决非线性优化问题，用于武器分配。
  - **狼群算法**：模拟社会等级和群体捕食行为，用于多目标分配。

### 3. 基于神经网络的方法

- **基于强化学习**：
  - MASAC（多智能体柔性行动器-评判器）：针对非完全信息场景设计奖励函数。
  - PER-MATD3：引入优先经验回放和TD3解决MADDPG的值函数高估问题。
  - **信用分配模型**（李潍团队[29]）：基于注意力机制的内部奖励网络 + 内部/外部奖励混合网络，根据智能体贡献度生成内部奖励，动态结合全局奖励。
  - **角色化MARL模型**（李潍团队[30]，MDDP）：角色定义方法 + 角色分配策略 + 动作价值估计双流架构，解决策略同质化问题。
- **基于深度学习**：ANN/CNN/模糊神经网络用于态势预测和机动决策，可自动提取特征。

## 关键参数/实验数据

本文为综述，未报告统一的数值实验对比。关键参数参考分布在各引用工作中：

- 态势优势函数影响因素：双方角度（a_A, a_B）、速度（v_A, v_B）、距离（d_AB）
- 粒子群算法参数：学习因子 c1, c2；位置 x_i、速度 v_i
- 蚁群算法参数：信息素重要程度因子 a，信息素挥发系数 alpha
- MASAC在无人机集群对抗博弈场景中取得良好性能，但不适用于异质集群
- PER-MATD3在障碍物随机分布的复杂环境下取得良好对抗效果
- 信用分配模型[29]：比现有代表性算法有望实现更快收敛速度和更高获胜率（论文用"有望"，为预期结论）
- 角色化MARL[30]：比现有代表性算法有望达到更快收敛速度、更佳鲁棒性及更高获胜率

## 结论

1. 三类算法各有限制：规则方法对未知场景适应差；博弈论方法依赖完全信息；神经网络方法需大量数据且缺乏可解释性。
2. 未来趋势是混合方法，将不同决策算法相互结合。
3. 深度学习的可解释性是制约其在严肃战场环境应用的关键瓶颈。
4. 仿真与实际作战环境差距大，需完善仿真平台并提高算法对不确定性的适应能力。

## 对本项目的可用点

1. **态势优势函数设计**：本文归纳的角度、速度、距离等态势因素及加权综合方法，可直接用于竞赛中红蓝双方的态势评估模块设计。
2. **博弈论框架**：纳什均衡求解思路（策略集 → 收益矩阵 → 均衡）可作为竞赛中对抗决策模块的理论基础，尤其适用于需要可解释决策的场景。
3. **群体智能算法**：粒子群、蚁群等算法可用于任务分配和路径规划子问题，特别是多机协同攻击目标分配。
4. **信用分配思路**：MARL中基于注意力机制的内部奖励设计，可借鉴用于多智能体协作时的奖励函数设计，解决团队贡献度量化问题。
5. **角色化决策**：MDDP的角色分配策略可用于设计异质化无人机编队的差异化决策，避免策略趋同导致的可预测性。
6. **限制条件**：本文主要面向军事对抗场景，部分假设（如纳什均衡求解的信息完备性）在竞赛环境中需根据实际规则调整；神经网络方法需要大量仿真数据训练，需评估竞赛时间约束是否允许。
