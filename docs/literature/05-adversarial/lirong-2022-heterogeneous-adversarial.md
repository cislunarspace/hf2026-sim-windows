## 一句话概括

针对性能异构无人机集群（A/B/C三种察打一体机），设计了组群对抗和分群对抗两种作战模式，从运动控制、动态网络拓扑、目标分配三个层级进行算法改进（改进Vicsek运动规则、自适应权值拓扑、改进拍卖算法），并通过MATLAB仿真平台验证了对抗有效性。

## 核心方法/模型

### 1. 三层异粒度分层建模框架

借鉴COMPACT模型，将集群对抗系统分为三层：
- **运动层**（精粒度）：单机六自由度运动学模型 + 集群SAC（分离-对齐-凝聚）运动模型
- **信息交互层**（中粒度）：平面交互网络拓扑 + 动态分簇网络拓扑
- **规划决策层**（粗粒度）：态势评估 + 目标分配

### 2. 组群对抗决策（第三章）

**运动层——改进Vicsek模型，非速度平均运动规则**：
- 设计五项速度规则：速度排斥（防撞）、速度对齐（协同）、速度引导（朝向敌群中心）、指定攻击（朝向分配目标）、协同攻击（朝向最近目标）
- 合成速度控制公式：v_next = k_p * v_p + k_u * v_u + k_g * v_g + k_a * v_a + k_c * v_c（公式3.12）
- 变系数控制器：根据有/无任务驱动动态调整权重系数，保留异构机型速度差异

**信息交互层——前向视野选择 + 自适应权值拓扑**：
- 前向视野选择机制：优先与位置前方友机通信，通过通信范围限制角 phi_Topo = pi/6 约束有效通信方向，用距离奖惩系数 sigma 重定义链路距离
- 自适应权值控制：通信量 W_ij = eta * D_i + (1-eta) * C_ij，D_i 为节点度差值归一化，C_ij 为通信距离比；当 W_ij 小于阈值时建立通信链路
- 通过平均节点度约束通信节点数量，实现负载均衡

**规划决策层——改进双向拍卖一致性算法**：
- 态势评估：威胁评估 T_ij = eta1*Ta + eta2*Tv + eta3*Th + eta4*Tr + eta5*Tc（角度、速度、高度、距离、固有效能五项加权）
- 综合态势收益矩阵 Z_ij = xi1 * T_val + xi2 * S_val（预期损失 + 预期收益）
- 拍卖流程：红方（买方）按预期收益报价，蓝方（卖方）按威胁值报价；通过一致性算法去重解决分配冲突；迭代至收益不再变化或达到轮次上限

### 3. 分群对抗决策（第四章）

**运动层——改进注意力跟随机制**：
- 设计领导者跟随模式下的排斥/对齐/引导三项规则，跟随者仅与领导者（簇头）进行速度对齐
- 分簇网络中的簇头自然担任领导者角色

**信息交互层——改进LEACH协议**：
- 基于节点竞争力的簇头选取：竞争力 C_i 由节点剩余能量、分布密度、稳定度（生存概率阈值分档）三因素综合决定
- 簇成员按通信距离最近原则加入簇头，簇头饱和时选择次近簇头

**规划决策层——改进组合拍卖算法**：
- 分层分配：先群级（子群 vs 子群），再个体级（UAV vs UAV）
- 群级态势评估：子群对单机的综合态势值为子群内所有成员态势值的平均
- 组合拍卖：红方子群为买方，蓝方单架为卖方，竞价机制 + 一致性去重

## 结论

1. 改进Vicsek非速度平均运动规则能保留异构机型的运动特性差异，同时实现集群协同运动
2. 前向视野选择 + 自适应权值拓扑有效降低通信节点数（A型UAV平均节点度从13降至设定值附近），提高通信质量
3. 改进双向拍卖算法在收益略降的情况下大幅降低预期损失（36.11 → 28.55），综合效果优于单向拍卖
4. 改进LEACH协议延长网络生存时间约 89%（35轮 → 66轮）
5. 分群对抗模式下参数过多，三个层级间参数关联不大，多数依靠经验设置，未使用智能优化调参
6. 局限：仅考虑性能异构（速度/攻击/通信），未涉及功能异构（侦察/干扰/歼击）；战场环境和通信模型均为理想化假设

## 对本项目的可用点

1. **分层建模框架**：运动层-信息交互层-决策层的三层架构可直接映射到竞赛仿真器的模块划分，各层独立开发、联合调试
2. **异构机型参数设计**：A/B/C三种机型的速度区间、攻击半径、杀伤率、携带量、价值等参数组合，为竞赛中异构无人机参数配置提供参考基线
3. **态势评估公式**：威胁评估五因素加权模型（角度、速度、高度、距离、固有效能）可直接用于竞赛的态势评估模块
4. **目标分配算法**：双向拍卖/组合拍卖算法的分配流程和一致性去重机制，适用于竞赛中的多对多目标分配场景
5. **非速度平均运动控制**：五项速度规则加权合成的控制器设计思路，适合异构集群的运动协同
6. **作战效能评估**：攻击收益（J_a）和毁伤代价（J_s）的评估公式，可作为竞赛评判指标的参考
7. **限制条件**：论文基于理想化假设（无风速、无干扰、固定翼无人机、海平面战场），与竞赛实际环境可能存在差异；分群对抗模式的参数调优问题需额外注意
