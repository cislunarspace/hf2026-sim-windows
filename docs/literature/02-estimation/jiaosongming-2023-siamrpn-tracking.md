## 一句话概括
用轻量骨干的 SiamRPN 做无人机对地目标的实时视觉跟踪，配合 HSV 图像处理解算目标偏航角、卡尔曼滤波做遮挡时的位姿预测，再用 PID 串级环实现轨迹跟踪，构成一套完整的"感知—估计—控制"闭环系统并在 Gazebo 仿真验证。

## 核心方法/模型

系统由四个模块串成闭环：

1. **单目标跟踪（SiamRPN + MobileNetv2 骨干）**
   - 模板帧（127×127）与搜索帧（255×255）分别送入孪生网络提特征，RPN 生成分类与回归两个分支，回归输出位置与尺寸的 4 个变化量，经非极大值抑制得到最终跟踪框。
   - 骨干网络选 MobileNetv2 而非 ResNet：ResNet 准确率平均高 18.1%，但识别速度低约 3 倍，机载算力下不可行。
   - 离线训练：ILSVRC2015_VID + 仿真环境自采集标注的小规模数据集；IoU>0.6 判为目标，<0.3 判为背景；分类损失权重 1、回归损失权重 1.2；SGD 训练 20 轮，学习率 0.005→0.0005，动量 0.9，权重衰减 1e-4。

2. **偏航角检测（HSV 颜色分割 + 几何解算）**
   - 在目标上放置"等边三角形 + 半圆"组合指向图标。从跟踪框截取图像，RGB 转 HSV 空间分割红色图标（H:158–180，S:45–255，V:46–255），边缘检测得轮廓。
   - 对轮廓做直线提取与角点检测，用 K-means 把多段线段聚为 2 条直线，再用角点坐标代入直线方程筛掉交点外的伪角点。按交点所在象限（4 个分支公式）由两直线与 x 轴夹角 θ₁、θ₂ 解算偏航角 ψ（图标两直线夹角 60°）。

3. **位姿估计 + 卡尔曼滤波轨迹预测**
   - 坐标系链：像素坐标 → 图像坐标 → 相机坐标 → 世界坐标，用无人机高度近似深度 z_c；相机固定于机体中心下方 0.01 m，已标定。
   - 卡尔曼滤波状态为四维 (s_x, s_y, v_x, v_y)ᵀ，恒速模型，状态转移阵 A 含时间项 t；观测向量由跟踪框经坐标变换得到的位置与速度构成。Q、R 取对角协方差阵。遮挡或运动突变时以预测值代替识别值送入控制，弥补 SiamRPN 遮挡丢失的缺陷。

4. **轨迹跟踪控制（牛顿-欧拉建模 + PID 串级）**
   - 四旋翼用牛顿-欧拉法建模并离散化，控制目标为位置与偏航角。
   - "位置-速度"外环与"角度-角速度"内环均由 PID 实现；位置外环设定值即被跟踪目标轨迹，升力方向向量与期望偏航角合成期望旋转矩阵送入姿态环。

## 关键参数/实验数据

| 类别 | 参数 |
|---|---|
| 网络输入 | 模板分支 127×127，搜索分支 255×255 |
| 训练 | 20 轮，SGD，lr 0.005→0.0005，动量 0.9，权重衰减 1e-4；分类/回归损失权重 1/1.2；IoU 阈值 0.6（目标）/0.3（背景） |
| HSV 红色分割阈值 | H 158–180，S 45–255，V 46–255 |
| 图标几何 | 两直线夹角 60° |
| 相机安装 | 机体中心正下方 0.01 m |
| 识别速率 | 33 FPS（NVIDIA Jetson NX，MobileNetv2 骨干） |
| 骨干网络对比 | ResNet 准确率高 18.1%，速度约慢 3 倍 |
| 适用高度范围 | 0.8 m ~ 4 m（>4 m 图标像素过低，<0.8 m 图标不完整） |
| 仿真硬件 | GPU NVIDIA 1050Ti，PyTorch + OpenCV，主程序 Python + C++ |

实验结论性数据：光照变化下不丢目标；完全遮挡时跟踪框漂移，无滤波会导致无人机短暂"失控"，加入卡尔曼滤波预测后仍稳定跟踪。

## 结论

- SiamRPN 的 RPN 结构避免了多尺度测试的时间代价，配合轻量骨干可在机载算力下达到实时（33 FPS）。
- HSV 偏航角解算 + 卡尔曼滤波预测，解决了纯视觉跟踪在遮挡、光照、姿态变化下的位姿丢失问题，轨迹平滑且贴近真实轨迹。
- 局限性：①图标识别有 0.8–4 m 的高度窗口限制（实际靠其他定位方式先接近目标再开启精细跟踪）；②算法部署到机载计算单元速度仍偏慢，作者提出未来用知识蒸馏压缩网络；③长时遮挡下的跟踪优化、避障与快速响应留作后续工作。

## 对本项目的可用点

- **估计模块直接可搬的范式**：四维恒速卡尔曼滤波（位置+速度）处理视觉观测，遮挡时用预测值接管控制——这与红枫 2026 中"视觉观测 → 目标状态估计 → 制导"的链路完全同构，状态向量设计、观测向量构造方式、Q/R 对角阵的整定思路都可直接参考。
- **坐标变换链**：像素 → 图像 → 相机 → 机体 → 世界的完整变换公式（式 2–4），尤其是"用无人机高度近似深度 z_c"这一单目下视相机的深度近似技巧，适合下视相机估计地面目标水平位置的场景。
- **轻量骨干选型依据**：MobileNetv2 vs ResNet 的精度-速度权衡数据（18.1% 精度换 3 倍速度），为仿真转真机时的模型选型提供了量化参考。
- **偏航角观测的思路**：若赛题需要估计目标朝向（而非仅位置），"指向性图标 + HSV 分割 + 几何解算"是一条不依赖深度网络的轻量路线；HSV 阈值和 60° 图标夹角是现成参数。
- **限制条件**：33 FPS 是 Jetson NX 上的结果，纯 CPU 仿真环境需评估算力；HSV 颜色阈值对仿真渲染色彩敏感，换环境需重新标定；高度窗口 0.8–4 m 提示视觉方案需配一个粗定位引导段。
