## 核心问题

UAV只有相机（无雷达/测距仪），观测为方位角+俯仰角，**无直接距离信息**——这是本项目的核心难点。

## 关键技术细节

### EKF 可观测性分析（Mai 2025）

- **核心结论**：单 UAV 直线运动时**距离不可观**
- **解决方案**：需要 UAV 做转弯/盘旋运动以获得观测几何变化
- **对本项目的影响**：搜索阶段必须设计螺旋/盘旋路径，不能直线飞行

### IMM 交互多模型（Mai 2025）

- **原理**：多模型并行运行，加权融合
- **适用场景**：目标机动转弯
- **对本项目建议**：CV + CT 模型组合，处理匀速和转弯两种运动模式

### SiamRPN + PID 控制（焦嵩鸣 2023）

- **架构**：轻量孪生网络跟踪 + HSV偏航角检测 + 卡尔曼滤波位姿预测 + PID串级控制
- **性能**：57.3 FPS
- **优势**：遮挡/光照干扰下的鲁棒性验证
- **对本项目的可用点**：卡尔曼滤波状态估计的设计思路、单目下视相机的深度近似方法

### 深度学习跟踪器（2026-dl-single-tracking-survey）

- **技术路线**：
  - Siamese 系列：SiamRPN++, TransT, OSTrack
  - CNN-Transformer混合
  - 全 Transformer
- **性能**：UAV123 上全 Transformer 最高 69.2% AUC（SimTrack）
- **实时性**：边缘设备 55-76 FPS

### 多尺度特征融合（黄宇航 2025）

- **架构**：MSFE 模块（1×1卷积通道加权）+ GLFF模块（Transformer+卷积并行）
- **性能**：UAVDT上成功率 0.533 / 精确度 0.742，均排名第一
- **速度**：145 FPS
- **对本项目跟踪模块**：可提供轻量实时基线方案

### DRL跟踪+避障融合（李治威 2026）

- **方法**：PPO + ANNs，端到端 DRL 融合控制
- **性能**：2.0 m/s 以下跟踪成功率 100%，单步推理仅 0.82-0.91 ms
- **局限**：状态估计依赖定高和平坦地面假设

## 对红枫 2026 竞赛的启示

### 1. 算法选型建议

| 算法 | 推荐度 | 理由 |
|------|--------|------|
| EKF | ★★★★★ | 计算简单，实时性好，适合 10Hz 决策 |
| UKF | ★★★★ | 更好的非线性处理，计算量可接受 |
| 粒子滤波 | ★★★ | 多模态处理强，但计算量大 |
| IMM | ★★★★ | 机动目标处理好，建议 CV+CT 组合 |
| SiamRPN | ★★★ | 实时性好，但需要 GPU |

### 2. 关键约束

- **观测几何**：必须设计螺旋/盘旋路径，直线运动下距离不可观
- **计算资源**：10Hz 决策频率要求算法轻量
- **遮挡处理**：需要设计丢失检测和重识别机制

### 3. 实施建议

1. **Phase 1**：使用 EKF + 盘旋观测几何
2. **Phase 2**：升级为 IMM（CV+CT模型）
3. **Phase 3**：考虑视觉辅助（SiamRPN）提高精度
