# 文献提取：状态转换机制驱动的无人集群"搜索–打击"联合决策方法

- **作者**：Wang N et al.
- **年份**：2026
- **来源**：中国科学（自动化学报方向），空军工程大学
- **原文路径**：`output/Wang 等 - 2026 - Joint search-attack decision-making method for UAV swarms driven by state transition mechanism/hybrid_auto/`

## 一句话概括

提出基于 SECA（State-Event-Condition-Action）状态转换机制的 UAV 集群"搜索–打击"联合决策方法（JSAD），将区域覆盖搜索与目标协同打击耦合在统一框架下，实现"发现即打击"。

## 核心方法/模型

### 整体架构：SECA 状态转换机制

将 UAV 任务状态划分为 5 种：搜索、盟首、投标、联盟、搜索（回收）。通过"状态–事件–条件–动作"模型定义状态间转换规则：

- **搜索 -> 盟首**：UAV 发现目标后自动成为招标者
- **搜索 -> 投标**：收到招标信息且满足投标条件
- **投标 -> 联盟**：被选入打击联盟
- **联盟 -> 搜索**：联盟完成打击后解散

### 搜索决策（Section 4）

1. **环境建模**：数字栅格地图，栅格属性三值（1=待搜索，0=已搜索，-1=非任务区），栅格尺寸 10m x 10m
2. **传感器模型**：探测范围为矩形区域，通过 Hadamard 积更新环境矩阵
3. **搜索决策函数**：三目标加权求和
   - J1：区域覆盖率增量（优先未覆盖栅格）
   - J2：地理围栏罚项（边界约束，罚值 10^6 / -10^6）
   - J3：偏航角调整代价（最小化航向变化）
   - 加权公式：J = w1*J1 + w2*J2 + w3*J3
4. **局部信息交互**：通过二值邻接矩阵确定通信范围内成员，Hadamard 积连乘环境地图矩阵实现信息共享，减少重复搜索
5. **求解算法**：差分进化算法（DE）

### 打击决策（Section 5）

1. **招标-投标模型**：发现目标的 UAV 发布招标信息（含目标属性、资源需求），其他 UAV 投标（含自身资源、到达时间）
2. **联盟组建优化**：最小化联盟成员到达目标的最长时间
   - 约束1：联盟资源覆盖目标需求（5 类资源的二值匹配）
   - 约束2：成员到达时间 < t_max
3. **冲突消解**：
   - 平台重复投标：投标状态锁定机制，投标期间不可再次投标
   - 目标重复探测：目标状态管理（未服务/被选定/已服务）

### 运动模型

匀速质点模型，离散状态空间方程，航向角控制变量离散化（间隔 Δθ = 45°）

### 仿真结果
- **单平台搜索**：5000s 覆盖率达 96.02%
- **多平台信息交互效果**（4 架 UAV，8km x 6km 区域）：
  - 通信距离 500m：覆盖率 67.02%
  - 通信距离 1000m：覆盖率 85.71%
  - 通信距离 2000m：覆盖率 84.22%
- **蒙特卡罗仿真（50 次，不同通信距离 0~8km）**：
  - 平均覆盖率：61.37% ~ 78.51%（通信距离增大覆盖率提升，但有饱和效应）
  - 平均目标清除数量：4.51 ~ 5.06（共 8 个目标）
- **与基线对比**：
  - 传统搜索+打击分离方法：发现到打击平均间隔 4622 s
  - JSAD 方法：发现到打击平均间隔 **244 s**（提升约 19 倍）

### 目标设置
- 8 个目标，每个目标资源需求均为 {1,1,1,1,1}（全部 5 类资源）
- 4 架 UAV，资源配置各异

## 结论

1. 将搜索与打击任务通过状态转换机制耦合，显著缩短打击响应时间（从 4622s 降至 244s），实现"发现即打击"
2. 局部信息交互能产生集群能力涌现效果，但通信距离与搜索效率呈非线性关系——超出阈值后效率不再显著提升，说明通信模块功率不必无限增大
3. 适用于面向时敏目标的侦打一体任务场景

**局限性**：
- 假设 UAV 间可通过预置高度/多跳中继实现防碰撞和通信
- 未考虑高度受限、通信失效/中断/丢包等约束
- 未考虑传感器探测不确定性

## 对本项目的可用点

1. **状态转换框架**：SECA 模型可直接用于竞赛中红枫平台的任务状态管理（巡逻/搜索/攻击/撤退等状态切换），状态机设计清晰且易于工程实现
2. **搜索决策函数**：覆盖率增量 + 地理围栏 + 航向代价的加权决策函数结构，可作为巡飞弹区域搜索的决策函数参考，权重参数（ω1:ω2:ω3 = 100:1:1）可作为初始调参基准
3. **联盟组建机制**：招标-投标模型可直接用于竞赛中多弹协同打击同一目标时的编组决策，资源匹配约束和时间约束的设计思路可移植
4. **冲突消解**：平台重复投标锁定机制和目标状态管理机制，对多弹场景下避免资源冲突有直接参考价值
5. **参数参考**：差分进化算法参数（种群 20、变异 0.8、交叉 0.7、迭代 15）可用于航向优化求解
6. **通信距离设计启示**：信息交互效率存在饱和效应，竞赛中通信距离设计不必追求极大值，需结合任务区域和集群规模通过仿真确定
7. **局限/注意**：该方法假设匀速运动质点模型，未考虑传感器不确定性和通信中断；竞赛场景中若存在电子对抗/通信干扰，需补充鲁棒性处理
