## 一句话概括

提出 BFBEL-P——一种免预训练、可在线自适应的模糊脑情绪学习轨迹预测模型，与 Reynolds 集群规则和 APF 避障结合，实现多无人机群在杂乱环境中对动态目标的实时协同跟踪。

## 核心方法/模型

系统由三个组件构成：

**1. BFBEL-P 预测模型（核心）**

基于双向模糊脑情绪学习（BFBEL），模拟大脑杏仁核–眶额皮层回路，前馈复杂度 O(n)。结构：感觉输入 → 高斯模糊隶属度编码 → 杏仁核/眶额皮层两个并行加权网络 → 差分输出。

- 模糊编码：$p_{ij} = \exp(-(i_i - \varsigma_{ij})^2 / 2\sigma_{ij}^2)$
- 情绪响应：$a_i = \sum p_{ij}v_{ij}$，$o_i = \sum p_{ij}w_{ij}$，控制输出 $u = a_i - o_i$
- 在线权重更新（奖励驱动，无梯度下降）：$\Delta v_{ij} = \alpha p_{ij}(R - a_i)$，$\Delta w_{ij} = \beta p_{ij}(u_i - R)$
- 强化信号：$R = q \cdot e_i + c \cdot u_i$

**预测机制**：对网络输出做时序分析，拟合三阶多项式外推 τ 步未来值；保留最近 5 个观测与预测拼接成候选序列；并行多次运行生成候选集，用三项误差准则（平方误差 φ₁、斜率偏差 φ₂、曲率失配 φ₃）筛选最优预测序列，滤除在线学习瞬态波动引入的噪声。

**2. 集群协调**：Reynolds boids 三规则（聚集/分离/对齐），各轴速度增量按 $\Delta x = (x_s - x)R_C + (x - x_o)R_S + (x_s - x_t)R_A$ 加权合成，支持集群分裂/汇合。

**3. 避障**：人工势场（APF）斥力势，$U_{rep} = \frac{1}{2}\eta(1/\rho - 1/\rho_0)^2$（$\rho \le \rho_0$ 时）。

**4. 分布式融合**：每架无人机多线程独立运行 BFBEL-P（10 Hz，预测 τ=5 步），预测发往中央飞控计算机做滚动平均融合；离群值剔除规则——偏离均值超过 2σ 的预测被排除，除非有 ≥2 架无人机形成共识。底层执行用 PID（Kp=0.5, Ki=0.1, Kd=0.01），控制频率 50 Hz。

**5. 稳定性证明**：基于 Lyapunov 的收敛分析，在模糊激活与奖励有界的假设下证明跟踪误差全局渐近收敛、权重更新有界。

## 关键参数/实验数据

**BFBEL-P 调参推荐值**：
- 学习率 α = β = 0.1；情绪调制系数 c = q = 1.2
- 每输入模糊隶属度函数数 n = 3；散布参数 σ_ij ∈ [0.3, 0.7]
- 奖励信号归一化到 [-1, 1]（Lyapunov 有界性要求）
- 滚动平均融合窗口 w ∈ [3, 5]

**仿真环境**：Ubuntu 20.04 + ROS Noetic + Gazebo，Parrot AR.Drone 2.0（ardrone_autonomy），60×60 m 场地，静态障碍 1.5×1.5×3 m 位于 (30,30,3)；目标走 8 字轨迹（幅值 50 m，周期 200 s）；机间通信固定延迟 100 ms；虚拟化四核 Jetson Nano 4 GB；每场景重复 10 次。

## 结论

BFBEL-P 在免训练、去中心化、抗遮挡/传感器退化方面优于曲线拟合与 LSTM，以可接受的精度损失换取部署可行性。局限性：未验证 4 架以上的扩展性（通信延迟、同步复杂度）；未在真实传感器噪声/漂移条件下测试；未建模风扰等突发环境扰动。未来方向：实机部署、异构传感器、与元启发式全局规划（PSO/ACO/GA）结合。

## 对本项目的可用点

- **协同跟踪/围捕模块**：Reynolds 三规则 + 目标吸引项的速度合成公式（式 17–19）可直接作为仿真中无人机群协同追踪目标的基线行为控制器，参数少、易实现、天然去中心化。
- **目标轨迹预测**：若需要在目标暂时丢失（遮挡）时维持跟踪，可参考其"短时窗口多项式外推 + 多候选误差筛选（误差/斜率/曲率三项）"的轻量预测思路；BFBEL-P 本身引入情绪学习层，复杂度较高，可先用其三阶多项式 + 筛选机制做简化版。
- **多机预测融合机制**：滚动平均 + 2σ 离群剔除 + 共识豁免规则，可直接借鉴用于仿真中多机观测/预测的信息融合，对"部分无人机丢数据仍能保持输出"的场景有参考价值。
- **参数参考**：通信延迟 100 ms、控制 50 Hz / 预测 10 Hz、预测窗口 τ=5、融合窗口 3–5，可作为仿真参数设定参照；8 字目标轨迹（幅值 50 m、周期 200 s）可作为目标机动测试用例。
- **限制条件**：所有结果为 Gazebo 仿真，未实机验证；短期精度（2.5–3 m）明显差于 LSTM，若竞赛评分重精度则该方法精度水平需注意；验证规模仅 4 架，更大规模群的通信与同步开销未知；APF 存在局部极小值等固有缺陷，文中未讨论。
