# 术语表 — 红枫 2026 无人集群竞赛

| 术语 | 定义 | 首次出现 |
|---|---|---|
| **UAV** | 无人飞行器，参赛方控制的无人机实体 | 赛题介绍 |
| **Agent** | 智能体，选手实现的 `decide(obs, dt)` 算法类 | SDK 规范 |
| **Obs** | 观测信息，包含 self/comm_inbox/briefing 三层 | SDK 规范 |
| **SelfView** | 本机状态：坐标、航向、云台、检测结果、通信状态 | SDK |
| **MissionBriefing** | 全局静态简报：地图边界、目标总数、威胁区近似范围 | SDK |
| **Detection** | 目标检测结果：detected/confidence/target_lat/lon/target_type | SDK |
| **盯防 (Dwell)** | UAV 持续对准同一真目标的有效跟踪状态 | 评分规则 |
| **摧毁 (Destroy)** | ≥K 架 UAV 同时盯防同一真目标累计 20s，目标永久清除 | 评分规则 |
| **协同阈值 K** | 摧毁目标所需的最少同时盯防 UAV 数：赛题二 K=2，赛题三 K=3 | 评分规则 |
| **中断容忍 (Grace)** | 盯防中断 ≤2s 不清零，>2s 清零重来 | 评分规则 |
| **诱饵 (Decoy)** | 伪装成真目标的干扰实体，视觉检测无法区分，靠运动学判别 | 赛题二/三 |
| **目标类型伪装** | 诱饵被引擎伪装为 `ground_vehicle`（同真目标），target_type 不可靠 | 评分说明 |
| **RMSE** | 均方根误差，衡量目指上报精度的指标 | 评分规则 |
| **D_max** | 精度容差：赛题一 30m，赛题二 120m，赛题三 150m | 评分规则 |
| **T0** | 用时基准：赛题二 240s，赛题三 360s，全歼 ≤T0 满分 | 评分规则 |
| **base_score** | 任务成就分（加权维度分之和），达标判定只看此项 | 评分规则 |
| **penalty** | 纪律扣分（过近 <200m / 越界 >500m，每次 2 分，上限 15 分） | 评分规则 |
| **SAM** | 地对空导弹防空区，UAV 进入滞留 ≥2s 必被击毁 | 赛题三 |
| **ApproxZone** | 近似威胁区描述（外扩 bbox + 面积 + 类型 + 高度带），无精确边界 | 赛题三 |
| **jammed** | 本机通信被干扰状态，仅能通过 `obs.self.jammed` 感知 | 赛题三 |
| **AccuracySimulator** | 默认识别器：按概率检出 + 高斯噪声（σ=50m），训练态使用 | 感知指南 |
| **EMA** | 指数移动平均，用于目标位置平滑和速度估计 | 基线算法 |
| **报告冻结** | 目标被摧毁后，对其的新上报被丢弃，RMSE 冻结在摧毁时刻 | 评分规则 |
| **A: 消息** | 协同认领消息 `"A:tgtidx,rank"`，用于 K=3 分布式共识 | swarm_coordinated |
| **D: 消息** | 确认诱饵消息 `"D:lat,lon"`，队友确认的诱饵位置 | swarm_coordinated |
| **J: 消息** | 干扰警告消息 `"J:lat,lon"`，被干扰时广播自身位置 | swarm_coordinated |
| **Bearing-Only Tracking** | 仅角度跟踪：UAV 只有相机（方位角+俯仰角），无直接距离信息（核心难点） | 文献调研 |
| **PyO3** | Rust 到 Python 的绑定框架，用于构建 Python 可 import 的扩展模块 | 构建系统 |
| **Maturin** | 基于 PyO3 的 Python 扩展构建/发布工具 | 构建系统 |
